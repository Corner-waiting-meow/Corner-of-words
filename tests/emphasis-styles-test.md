# 黑白屏文字强调方式对照

这是一份用于文石 P6+ 的 EPUB 排版测试。请在相同的阅读字号、字体及显示设置下比较以下效果。每一行都包含同一句测试文字：**命运与选择之间的关系**。

## 一、单行对照

**01｜普通加粗（Strong）**

这里的关键词是 **命运与选择之间的关系**，请观察它和普通字的字重区别。

**02｜粗体 700（CSS）**

这里的关键词是 <span class="weight700">命运与选择之间的关系</span>，请观察是否与普通加粗不同。

**03｜更粗的 900（CSS）**

这里的关键词是 <span class="weight900">命运与选择之间的关系</span>，看看阅读器是否真的增加字重。

**04｜原生高亮 mark（不指定颜色）**

这里的关键词是 <mark>命运与选择之间的关系</mark>，看看阅读器如何默认渲染高亮。

**05｜浅灰底高亮（#dddddd）**

这里的关键词是 <mark class="graylight">命运与选择之间的关系</mark>，观察灰底与黑字的区别。

**06｜深灰底高亮（#888888）**

这里的关键词是 <mark class="graydark">命运与选择之间的关系</mark>，观察在黑白屏上的对比度。

**07｜黑底白字反白（#000000 / #ffffff）**

这里的关键词是 <mark class="inverse">命运与选择之间的关系</mark>，观察反白对阅读连贯性的影响。

**08｜下划线（无背景色）**

这里的关键词是 <span class="underlined">命运与选择之间的关系</span>，与高亮和加粗对照。

## 二、跨行与实际阅读

下面几段用于观察较长的强调文字是否发生断裂、底色不连贯、行高异常或分页问题。

**灰底长句：** <mark class="graylight">命运并不总是与个人行动相对立。有时，行动本身就是抵达某种未来的路径，而偶然的相遇也可以被理解为命运的一部分。</mark>

**反白长句：** <mark class="inverse">命运并不总是与个人行动相对立。有时，行动本身就是抵达某种未来的路径，而偶然的相遇也可以被理解为命运的一部分。</mark>

**普通加粗长句：** **命运并不总是与个人行动相对立。有时，行动本身就是抵达某种未来的路径，而偶然的相遇也可以被理解为命运的一部分。**

## 三、判断记录

优先比较：辨识度、阅读干扰、跨行表现、字号调整后的稳定性，以及在默认与自定义字体下是否有差异。

本测试不修改正式书籍的加粗语义和排版规则。
